## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

`main.ts` reads `POST.json` next to it (the X post URL, written after the meme is posted), validates it is an `https://x.com/<handle>/status/<id>` link, and writes only a canonical `POST.json` into `MAKEFUN_OUTPUT_DIR`. Node 22, stdlib only, no dependencies.
